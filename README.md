# AERO-SHIELD X: AI-Powered Aerospace Cyber Defense Platform

An edge AI cybersecurity platform that detects and classifies cyber-attacks in real time, with an analytics dashboard for incident investigation and a blockchain-backed evidence ledger.

## Features

- **Real-time attack detection:** Combines Isolation Forest and Autoencoder models for anomaly detection and attack classification, with on-edge inference.
- **Incident investigation:** Full-stack analytics platform for reviewing detected events.
- **Tamper-proof evidence ledger:** Solidity smart contracts with SHA-256 hashing record evidence on-chain.
- **Secure API:** RESTful endpoints for the dashboard and integrations.
